src/
├── assets/        # 이미지, 폰트, 아이콘 등 정적 자산
├── components/    # 재사용 가능한 소규모 컴포넌트들 (버튼, 카드, 모달 등)
├── pages/         # 라우트에 대응하는 페이지 컴포넌트들
├── hooks/         # 커스텀 훅 모음 (ex: useAuth, useFetch)
├── services/      # API 요청 함수들 (ex: axios 호출 모음)
├── contexts/      # Context API 관련 코드들 (ex: AuthContext)
├── utils/         # 유틸 함수들 (ex: 포맷팅, 계산 로직)
├── constants/     # 상수 모음 (ex: API 주소, 에러 코드)
├── layouts/       # 여러 페이지에 공통으로 적용되는 레이아웃 컴포넌트
├── router/        # react-router 설정
├── store/         # 상태 관리 (redux, recoil, zustand 등)
├── styles/        # 전역 스타일(css, scss, styled-components theme 등)
└── App.tsx        # 앱 엔트리 포인트
└── main.tsx       # (Vite 기준) 루트 렌더링 파일

2. 각 폴더 역할 요약

폴더	역할
assets/	이미지, svg, 폰트 저장
components/	여러 곳에서 재사용하는 소규모 UI 컴포넌트
pages/	각각의 페이지. 라우팅과 직접 연결됨
hooks/	커스텀 훅 관리
services/	API 요청 보내는 함수들
contexts/	글로벌 상태 공유 (Context API 사용 시)
utils/	순수 함수, 헬퍼 함수
constants/	상수들 (API 주소, 에러 코드 등)
layouts/	페이지들의 공통 골격(헤더, 푸터 포함)
router/	라우터 설정 파일 (ex: react-router)
store/	전역 상태 관리 관련 코드 (redux, recoil 등)
styles/	글로벌 스타일 파일, 테마 설정
